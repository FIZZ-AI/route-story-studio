# Bundled visual system

Original anonymous watercolor atlas illustrations and fictional traveler portrait generated for this reusable package with the host image-generation tool. No personal photographs, real-person avatar or itinerary is included. Maps depict fictional compositions and are style templates, not surveys of named places.

Font: LXGW WenKai, distributed unmodified with its upstream OFL-1.1 notice in fonts/OFL.txt. See fonts/source.json for provenance and hash.

Music recordings are not redistributed in this package. The default selection catalogue stores official source pages; obtain recordings only by acquisition methods allowed by the source terms, and check their licence in the user's project.
